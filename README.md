# Overcenter Research

> **Research repository only.** This repository contains architectural research, design notes, experiments, and prior-art analysis for Overcenter. It is not an Overcenter runtime, deployment source, verification target, or implementation repository.

## Boundary

Use this repository to preserve research and design conclusions that may inform Overcenter.

Do **not** treat this repository as:

- executable Overcenter source;
- a Hatchable deployment source;
- a runtime or verification environment;
- the authority for current Overcenter implementation state.

The active Overcenter implementation and its deployment/verification surfaces remain separate from this research repository.
